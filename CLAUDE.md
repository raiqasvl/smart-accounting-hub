# smart-accounting-hub — agent guide

Guidance for coding agents working in this repo. This file is read as both **`AGENTS.md`** and
**`CLAUDE.md`** (`AGENTS.md` is a symlink to this file — edit here). Keep it short: the deep design
lives in `STRUCTURE.md` and `thoughts/`.

## What this project is

Telegram-Mini-App-driven personal/family/business **FX accounting** tool. Headline feature:
**weighted-average exchange-rate** across stored FX transactions. MVP is **local-dev only** —
deployment + CI are deferred.

- Single-page architecture / mental model → `STRUCTURE.md`
- Quickstart + daily local-dev flow → `README.md`
- Locked decisions D1–D32, milestones M1–M5, background research → `thoughts/shared/{plans,research}/`

## Stack (locked)

Python 3.12 (uv workspace) · aiogram 3.x + aiogram-dialog · FastAPI + Pydantic v2 ·
SQLAlchemy 2.x async + asyncpg · Postgres 16 (`ltree`) · Redis 7 (FSM only) · Alembic · Dishka.
Next.js 15 + TS · TanStack Query · shadcn/ui · Tailwind · Recharts (pnpm + Turborepo).
Types cross the boundary via OpenAPI → `openapi-typescript` → `packages/api-types`.

## Setup & run (local dev)

```bash
make bootstrap        # one-time: uv sync --all-packages + pnpm install
cp .env.example .env  # fill BOT_TOKEN, JWT_SECRET, DOMAIN — see docs/bot-setup.md
make up               # postgres + redis in docker (the only containers we run)
make migrate          # alembic upgrade head
```

Then run each process in its own terminal:

```bash
make dev-api          # FastAPI on :8000 (uvicorn --reload)
make dev-bot          # aiogram polling worker
make dev-miniapp      # Next.js on :3000
make tunnel           # cloudflared → public HTTPS so Telegram can load the Mini-App
```

Other: `make revision M="msg"` (new autogenerated migration) ·
`pnpm run types:gen` (regenerate `packages/api-types` from the running API's OpenAPI).

## Checks — run before calling work done

```bash
make check            # full gate: lint + format + typecheck + test
# …or individually:
make lint             # ruff check + oxlint (pnpm lint)
make format           # ruff format + prettier
make typecheck        # mypy (strict) + tsc
make test             # pytest + pnpm -r test
```

- **Python**: ruff (lint+format) + mypy **strict** + pytest (`asyncio_mode=auto`). Config in root `pyproject.toml`.
- **TS/TSX**: **oxlint** (no ESLint) + Prettier. Configs `.oxlintrc.json`, `.prettierrc`.

## Hard rules (do not violate)

- **Money**: `NUMERIC(20,8)` in Postgres, `Decimal` in Python, **string in JSON** (D23; see `packages/core/.../schemas/money.py`).
- **Tenancy**: every domain row is `book_id`-scoped; RBAC per `(book_id, user_id) → role`.
- **Errors**: return `{ error: { code, params }, request_id }` — language-agnostic codes. i18n lives in the bot/Mini-App layer, never in `packages/core`.
- **Bot bypasses HTTP (Q4/D22)**: `apps/bot` calls `smart_accounting.services.*` directly; it **never** imports `smart_accounting.{models,repositories}` and **never** calls `apps/api` over HTTP. CI grep-guard enforces this.
- **Layering** inside `packages/core`: presentation (routers / handlers / dialogs — call exactly one service) → `services/` (the only place a transaction begins and ends) → `repositories/` (queries only, no business rules, no tx) → `models/` (SQLAlchemy only, no logic). `schemas/` (Pydantic wire) and `models/` (ORM) never share types.
- **Dependency DAG**: `packages/core` imports nothing from `apps/`; `apps/api` and `apps/bot` never import each other; `apps/miniapp` imports only `packages/api-types`.
